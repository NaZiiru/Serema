Introduction
============

La stack ELK est composée de trois outils open-source :

- **Elasticsearch** : moteur de recherche et de stockage
- **Logstash** : collecte et transformation des données
- **Kibana** : visualisation et dashboards

Avec **Kafka**, cette stack devient un pipeline temps réel robuste.

.. note::
   Cette documentation couvre l'installation et la configuration
   complète du pipeline Kafka → Logstash → Elasticsearch → Kibana.
